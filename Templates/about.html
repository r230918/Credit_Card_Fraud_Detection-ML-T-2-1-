Problem Statement

Credit card fraud represents a severe financial threat, generating billions of dollars in global losses annually. Because fraudulent anomalies account for an extremely small fraction of total transaction volumes, the dataset exhibits extreme class imbalance. The objective of this project is to develop and evaluate Machine Learning classification models capable of robustly detecting fraud indicators while maintaining a low rate of false alarms to prevent transaction friction.

About the Project

FraudShield is a specialized Machine Learning analytics workspace developed to ingest, clean, diagnostic-check, and visualize financial transaction datasets. It provides a modular pipeline framework that prepares raw features for predictive modeling.

Pipeline Workspaces:

  • Automated Data Cleaning: Removes duplicate records and automatically imputes numerical missing fields using column-wise median computations.
  • Interactive Data Docs: Displays complete transaction features and target labels in a paginated grid interface.
  • Exploratory Data Analysis: Visualizes class proportions and amount distributions using Matplotlib to diagnose imbalances.
